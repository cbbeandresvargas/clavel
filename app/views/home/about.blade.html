Sobre ClaVel 🌸

Un framework MVC de alto rendimiento que combina la velocidad de C con la expresividad de Laravel.

🎯

La visión

ClaVel nació de una pregunta: ¿qué pasaría si pudieras escribir aplicaciones web tan fácilmente como en Laravel, pero que compilaran a un binario de 3 MB listo para producción?

⚙️

Cómo funciona

El CLI clavel transpila tus vistas Blade y embebe tus assets en tiempo de build. El resultado es código C nativo que compila con GCC o Clang a un ejecutable autocontenido.

🚀

Stack técnico

Servidor HTTP con Mongoose · Arena Allocator por petición · SQLite3 embebido · Transpilador Blade-to-C · CMake cross-platform.

El stack completo

Todo lo que necesitas, en un solo binario.

🌐
Mongoose HTTP Server

Single-file C HTTP server con soporte WebSocket

🧠
Arena Allocator Memoria

1 MB por request, liberado en un paso. Cero leaks.

🗄️
SQLite3 Base de Datos

Embebido directamente. Sin servidor externo.

🔨
clavel-cli Build Tool

Transpila Blade → C y embebe assets en el build.
