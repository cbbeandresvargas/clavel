¿Por qué ClaVel?

Velocidad de C, ergonomía de Laravel.

🧠

Arena Allocator

Un bloque de 1 MB por petición HTTP. Liberación automática al responder. Cero free() manuales. Imposible filtrar memoria por request.

🛣️

Router Dinámico

Parámetros {slug}, verbos HTTP, y middlewares encadenables. Escritura limpia con Route_get("/ruta", Handler);

🎨

Vistas Blade compiladas

Escribe {{ variable }} y @if. El CLI las convierte a funciones C en tiempo de build. Auto-escape HTML anti-XSS.

🗄️

ORM Encadenable Próximamente

SQLite embebido en el binario. Query builder estilo Laravel: DB_table("users")->where("id","=","1")->first()

📦

Binario único

Assets CSS/JS embebidos como arrays de bytes. Sin dependencias en runtime. scp el binario al servidor y listo.

🔒

Seguridad por defecto

Prepared statements anti-SQLi, auto-escape anti-XSS, tokens CSRF y firmado de cookies HMAC-SHA256.

// app/routes.c — Define todas tus rutas
#include "../framework/router.h"
#include "controllers/producto_controller.h"

void register_routes(void) {
    Route_get("/productos",        ProductoController_index);
    Route_get("/productos/{slug}", ProductoController_show);
    Route_post("/productos",       ProductoController_store);
}
// app/controllers/producto_controller.c

void ProductoController_show(Request *req, Response *res) {
    // 1. Parámetro de URL capturado automáticamente
    const char *slug = Request_param(req, "slug");

    // 2. ORM encadenable (Fase 4)
    Producto *p = DB_table("productos")
                    ->where("slug", "=", slug)
                    ->first();

    if (!p) return Response_abort(res, 404);

    // 3. Pasar datos a la vista Blade
    TemplateData *d = TemplateData_new(req->arena);
    TemplateData_set(d, "nombre", p->nombre);
    TemplateData_set(d, "precio", p->precio_str);
    View_render(res, "productos.show", d);
}
